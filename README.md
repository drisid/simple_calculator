# React Calculator

A simple responsive calculator built with React and Vite.

## Features

- Addition, subtraction, multiplication, and division
- Decimal numbers and delete/backspace
- Clear and equals controls
- Keyboard support
- Responsive calculator interface

## Keyboard controls

- Numbers: `0`–`9`
- Operators: `+`, `-`, `*`, `/`
- Decimal: `.`
- Calculate: `Enter` or `=`
- Clear: `Escape`
- Delete: `Backspace`

## Development

```sh
npm install
npm run dev
```

Build for production:

```sh
npm run build
```
